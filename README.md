One line summing up the entrant's week: three features shipped, prod broken twice, and one plant killed — the plant is the only one missed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network, no randomness) writes the entry line to `/output/entry.txt` — 92 characters, inside the gate's 1–100 characters — so both grader runs write identical bytes.
